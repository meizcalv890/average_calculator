# Average Calculator

A simple calculator designed specifically to calculate the average of numerical values.

## Features

- Calculate the average of multiple numbers.
- Simple and focused interface.
- Clear calculation results.
- Easy input and calculation process.
- Responsive design.

## Built With

- HTML
- CSS
- JavaScript

## Formula

Average = Sum of Values / Number of Values

## Overview

Average Calculator is a lightweight calculation tool focused entirely on average calculations without unnecessary features.
